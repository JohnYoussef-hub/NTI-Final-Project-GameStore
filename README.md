# 🎮 NTI Final Project — Game Store

A simple **Full-Stack Game Store** built with **Node.js, Express.js, and React.js** as part of the NTI training final project.

## 🚀 Features

### 1. Authentication

* User Registration
* User Login
* JWT Authentication
* Password Hashing

### 2. Games CRUD

* Create Game
* Get All Games
* Get Game by ID
* Update Game
* Delete Game

### 3. Users & Wishlist

* User Profile
* Update User Profile
* Add Game to Wishlist
* Remove Game from Wishlist
* View Wishlist

## 🛠️ Technologies

* **Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, bcrypt
* **Frontend:** Angular
