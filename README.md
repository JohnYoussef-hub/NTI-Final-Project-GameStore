A **Full-Stack Game Store** built with **Node.js, Express.js, and Angular** as part of the NTI training final project.

## ✨ Features

### 🔐 1. Authentication
* User Registration
* User Login
* JWT Authentication
* Password Hashing

### 🕹️ 2. Games CRUD
* Create Game
* Get All Games
* Get Game by ID
* Update Game
* Delete Game

### 👤 3. Users CRUD
* Create User
* Get All Users
* Get User by ID
* Update User
* Delete User

### ❤️ 4. Wishlist
* Add Game to Wishlist
* Remove Game from Wishlist
* View Wishlist

## 🛠️ Technologies
* **Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, bcrypt
* **Frontend:** Angular
